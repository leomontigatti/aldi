Antes de empezar: tu clave de Gemini

Aldi traduce con Gemini, de Google. Para usarlo necesitas una clave gratuita, que se crea una sola vez:

  1. Entra en aistudio.google.com/apikey con tu cuenta de Google.
  2. Si te lo pide, acepta las condiciones de uso.
  3. Pulsa Create API key («Crear clave de API»). Si te pregunta por un proyecto, elige el que te ofrece.
  4. Cuando aparezca la clave (empieza con AIza), pulsa el botón de copiar.
  5. Vuelve aquí, pégala abajo y pulsa Guardar clave.

Es gratis: no hace falta tarjeta ni suscripción.
